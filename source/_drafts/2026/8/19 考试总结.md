## 题目概述

省流：$ 0 + 68 + 8$ ， T1 直接坠机了。

首先 T1 本来非常简单。结果我犯了一个弱智错误：

```cpp
cin >> n >> k;

if(n <= k) { cout << 0 << '\n'; } // 这里没有写 return

for(int i=1; i<=n; i++) cin >> a[i];
for(int i=1; i<n; i++) b[i] = a[i+1] - a[i];

sort(b+1, b+n, greater<>()), k--;

ll ans = a[n] - a[1];
for(int i=1; i<=k; i++) ans -= b[i];
cout << ans << '\n';
```

然后这一次整个下来实际上问题最大的实际上就是因为 T2, T3 的大样利太水了。

T2 做的非常的快。然后本来大样例全过了的。但是由于大样例太水了。因此我就去打了一个对拍。然后结果我一直拍的都有问题，最后调试了一个小时之后才发现是 `data.cpp` 写错了。

T3 可以说是一眼出思路。然后进去之后大样例过的也十分顺利。然后自己测试了几种特殊情况也没有问题就了。但是结果他要求的是四联通块而不是八联通块。本来还对于这个有所怀疑，但是这道题的样例专门做成一个八连通块的样式。

由于回去看 T2 的对拍问题了，就连 T4 都没有看。
